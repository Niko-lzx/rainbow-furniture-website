## 品牌统一口径

虹桥办公家具 / Rainbow Furniture 创立于1999年，位于中国佛山顺德龙江，拥有40万㎡现代化生产基地、2万㎡现有实景展厅，并有4万㎡新展厅正在装修升级中。

虹桥专注中高端办公家具整体配套，围绕总裁办公室、会议室、员工办公区、接待区、洽谈区及各类工程项目，为企业客户、设计公司、经销商和海外客户提供从产品选型、空间搭配、生产制造、项目交付到售后服务的一站式办公空间解决方案。
